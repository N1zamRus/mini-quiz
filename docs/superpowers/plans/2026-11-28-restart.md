# Restart Quiz Implementation Plan

**Goal:** Выполнить issue № 3: начать новую попытку без перезагрузки.

**Architecture:** По кнопке результата создаётся новый `Quiz` из существующих вопросов; интерфейс возвращается к первому вопросу и переносит фокус на первый ответ.

**Tech Stack:** HTML, JavaScript, Node.js; без новых зависимостей.

**Spec:** Критерии issue № 3 и согласованный с пользователем вариант в диалоге.

## Global Constraints
- Счёт, номер вопроса и состояние ответа новой попытки не зависят от предыдущей.
- Пустой список вопросов по-прежнему безопасно считается завершённым.

## Review Focus
- Первая попытка с правильными ответами, вторая с неправильными: новый счёт равен нулю.
- Повторная попытка со смешанными ответами: итог соответствует только ей.
- Старый результат и обратная связь скрыты после нажатия.
- Кнопка повтора работает с клавиатуры; фокус получает первый ответ.
- Несколько повторов не перезагружают страницу и не накапливают обработчики.
