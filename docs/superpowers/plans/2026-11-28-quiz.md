# Mini Quiz Implementation Plan

**Goal:** Выполнить issue № 1: викторина с проверкой ответов и итоговым счётом.

**Architecture:** Статическая страница последовательно показывает вопросы и результаты ответов; JavaScript хранит состояние текущей попытки без сервера.

**Tech Stack:** HTML, CSS, JavaScript; Node.js для проверок.

**Spec:** Issue № 1 и согласованный в диалоге вариант статической страницы без зависимостей.

## Global Constraints

- На каждый вопрос можно ответить один раз; после ответа показывается результат.
- После последнего вопроса итог равен количеству правильных ответов.
- Страница работает без сервера и сторонних зависимостей.

## Review Focus

- Неверный ответ не увеличивает счёт.
- Повторное нажатие не засчитывает ответ повторно.
- Смешанные ответы дают правильный итог.
- Результат последнего ответа виден до перехода к итогу.
- Кнопки доступны с клавиатуры.
