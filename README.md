# mini-quiz
Небольшая викторина с вопросами, вариантами ответов и подсчётом результата.

Откройте `index.html` в браузере, выберите ответ на каждый вопрос и перейдите к следующему. После последнего ответа появится итоговый счёт и кнопка для повторного прохождения.

Автоматические проверки: `node test.js` (нужен Node.js).
